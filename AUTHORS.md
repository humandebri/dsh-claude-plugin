# Authors and provenance

This repository is an original implementation created for this project.

- **snowan** — project owner, human author, reviewer, and Git commit author.
- **Codex** — AI development assistant used for research, design, implementation,
  testing, and documentation.

Git commits intentionally use only snowan's configured name and email. Codex is
credited here instead of through `Co-authored-by` trailers so GitHub contributor
attribution remains limited to the repository owner.

No commit history or source code is imported from DeepSeek Harness, its bundled
Claude subagent, another DSH adapter, or a similarly named open-source project.
Those projects may be inspected as external interfaces or comparative evidence,
but implementation is written independently against documented contracts.
